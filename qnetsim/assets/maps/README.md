# Map data

`ne_110m_land.geojson` is Natural Earth's public-domain 1:110m land dataset.
Downloaded 2026-09-25 from the project maintainer's repository:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Dataset: https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/

Terms: https://www.naturalearthdata.com/about/terms-of-use/

Used for scientific map backgrounds without political boundaries. Each generated
pass report records the local dataset SHA-256 for reproducibility.
